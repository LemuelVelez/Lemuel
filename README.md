# Lemuel Velez — Full-Stack Developer Portfolio

A responsive portfolio built with React, Vite, and Tailwind CSS. It presents Lemuel Velez’s full-stack projects, professional experience, technical skills, education, and graduation highlights.

## Featured projects

- PAC Online Payment — Next.js, Appwrite, PayMongo
- SurveyStat — React.js, Express.js, Node.js, PostgreSQL
- Attendance Repository — React.js, Go, PostgreSQL, Redis
- BookHive — React.js, Express.js, Node.js, PostgreSQL
- Penalyze — React.js, Express.js, Node.js, PostgreSQL
- SSG QR Code Generator — Next.js
- SSG QR Code Scanner — Expo, React Native, WatermelonDB

## Local setup

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

No environment variables or additional asset downloads are required.
